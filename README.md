# NumPy Visualisasi

Visualisasi interaktif untuk materi NumPy dengan dataset penjualan empat cabang.

## Menjalankan lokal

\`\`\`sh
npm install
npm run dev
\`\`\`

## Build

\`\`\`sh
npm run build
\`\`\`

Angka pada tampilan dihitung untuk membantu belajar. Kode NumPy yang ditampilkan dapat disalin ke notebook.
